        Painel de baixo

        SAÍDA: o que o programa imprimiu (console.log, puts, print...).

        PÁGINA: se o .larp tiver HTML/CSS, a página aparece aqui. Ela abre sozinha quando existe.

        PYTHON: o código Python que a LARP gerou a partir do seu.

        Deu erro? Clique no 📍 linha N da SAÍDA e o editor pula até ela (a linha fica sublinhada em vermelho).

        ENTRADA: respostas para input() / prompt(), uma por linha, escritas antes de rodar.

        Como funciona

        Cada linha do seu .larp é traduzida para Python, e esse Python roda aqui mesmo no navegador (com o Pyodide). Nada vai para servidor nenhum.
